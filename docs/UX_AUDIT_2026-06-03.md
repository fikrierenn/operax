- **CSRF / `@Html.AntiForgeryToken()` eksik** (Finans Cheques/Loans Details + Admin Users/Roles/Modules/Budget/Dictionary): Ajanlar "eksik" dedi AMA Razor Pages `FormTagHelper` `<form method="post">`'a token'ı **otomatik enjekte + doğrular**. ## 2. YÜKSEK — Sistemik temalar (çok ekran)

### T1 — Dekoratif filtreler (arama/filtre çalışmıyor, server'a bağlı değil)
Items/Index, Partners/Index, Warehouses/Index, Inventory/Balance, Inventory/Movements, Receiving/Index, Transfer/Index, PurchaseOrders/Index (chip+sayfalama).
→ `OnGetAsync(string? q, ...)` + SQL `WHERE LIKE @q` + `<input name="q" value="@Model.Filter">`. **Inventory/Balance'ta TOP yok → performans riski.**

### T2 — Tam İngilizce ekranlar (turkish-ui.md ihlali)
**Picking/Details** (tüm tablo/buton/banner), **Production/Details** (tüm UI), **Locations/Index** (tüm), **Dictionary/Details** (tüm). + onlarca İngilizce `data-screen-label`/başlık (Purchasing List, Sales List, Sales Invoices, Price Variances, Admin Parameters, Putaway/Replenishment Wizard, Picking ...).
→ Türkçeleştir.

### T3 — Hata yönetimi yok (sessiz fail, beyaz sayfa riski)
SalesOrders/Details (OnPostAsync+OnPostAddLine), Shipping/Details (+ OnPostAddLine + Terminal/Scan), Production/Details (LoadBOM/CreatePickTask/Finish + Terminal `throw;`), BOM/Details (3 handler), WorkCenters/Index.
→ try/catch (SqlException >=50000 → TempData.Error) pattern uygula.

### T4 — Otomatik doldurma + hardcoded KDV
SalesOrders/Details: ürün→satış fiyatı (Item.SalesPrice) gelmiyor; **KDV %20 hardcoded** (SO `*0.20m` + PO Details `%20` görüntü). Satır bazlı `TaxRatePercent` kullanılmalı.
WorkOrders/Details: iş merkezi→standart maliyet otomatik gelmeli. Cheques/Create: cari→DrawerName. Loans/Create: LoanNo NumberSeries'ten.

### T5 — Başarı mesajı yok (sessiz başarı)
Items/Details, Warehouses/Details, Partners/Details (set ediliyor ama view'da render yok), PurchaseOrders/Details OnPostCancel.
→ `TempData["Success"]` set + view'da `alert-banner` render.

### T6 — POSTED durumda alanlar editable (immutability UI eksik)
Receiving/Details + Shipping/Details: POSTED'da Depo/Tedarikçi/Plaka hâlâ `<select>/<input>`. Server guard yoksa kayıt değişebilir.
→ POSTED ise readonly görünüm + handler guard.

### T7 — İşlevsiz/placeholder butonlar
Picking/Index "Yeni Toplama"+"Filtrele", Production/Index "Yeni İş Emri" (oluşturma ekranı YOK), Locations "Yeni Depo/Bin Ekle", LPN/Details "Paleti Taşı", StatusTransitions "Yeni Geçiş", Dictionary "Yeni Tip/Değer/Düzenle".
→ Çalışan handler bağla VEYA `disabled`+tooltip ("yakında").

### T8 — Satır "Çıkar" işlevsiz
Receiving/Details + Shipping/Details: DRAFT'ta satır silme butonu handler'sız.
→ `OnPostRemoveLineAsync` + form (DRAFT guard).
