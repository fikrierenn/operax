# Operax El-Terminali (Mobil/Handheld WMS) UX Araştırması — 2026-06-03

Kanıtlı handheld WMS terminal UX (Zebra, NNGroup, Scandit, UXmatters, Material, Microsoft D365).
Özet kurallar → `.claude/skills/ux-design-patterns/SKILL.md` "MOBİL / EL-TERMİNALİ" bölümü.

## 6 kategori
1. Ortam + tek görev (bir ekran=bir soru, minimum UI, offline-dayanıklı, Türkçe emir kipi)
2. Barkod-tarama-öncelikli (scan-first/type-fallback, 3-kanal geri bildirim ≤200ms, spesifik hata)
3. Dokunmatik hedef (48dp min / 60dp birincil eldiven, thumb-zone alt %40)
4. Mobil giriş (inputmode numeric, büyük input 56px/20px, autofocus, akıllı varsayılan, ≤3 zorunlu)
5. Geri bildirim (tam ekran başarı/hata, ilerleme sayacı, bağlantı durumu, onay modalı)
6. Görsel (font ≥20px, kontrast 7:1, koyu zemin, sayfalama, renk+ikon+metin)
